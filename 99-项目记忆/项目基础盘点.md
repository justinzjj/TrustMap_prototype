# 项目基础盘点

## 盘点日期

2026-07-20

## 项目一句话理解

这是一个从论文与旧实验附件重新出发的生产化原型仓库，目标不是继续模拟，而是提供真实事件驱动、可恢复、可验证的 MapNode 和本地多 Geth 链环境。

## 我检查了什么

- `TrustMap_prototype` 的文件、Git 状态、分支、远端和最近提交。
- `TrustMap-ETH` 当前分支的 README、Solidity 合约、Go binding/测试、TypeScript 回放脚本、Python 模拟器和 Geth genesis。
- `TrustMap-ETH` 历史 `TrustMap4` 分支的 relayer 结构、核心类型、SDK、transport、verification 和 trustmap 层。
- TrustMap 论文的 Overview、TrustMap、Security Analysis、Implementation and Evaluation、Discussion 与 Preliminaries。
- Geth 官方 developer mode、CLI、private network 与 release 信息。

## 关键发现

- 新仓库是干净的设计起点。
- 旧合约包含增量 Merkle frontier 和递归证明的实验实现，但不是可直接发布的生产 ABI。
- 旧 MapNode/relayer 没有完成真实链监听、proof generation、shortest path、持久化和 P2P 更新闭环。
- Python 代码主要服务于时间有序 trace simulation 和评测，不是守护进程。
- 论文明确允许本地 TrustView 不一致，并要求链上 verifier 保持最终接受权。
