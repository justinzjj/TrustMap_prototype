# TrustMap Prototype 项目记忆

这是本仓库的嵌入式项目记忆入口，用于让后续 Codex、开发者和并行任务快速恢复设计上下文，避免重复扫描论文与旧实验仓库。

## 推荐读取顺序

1. `manifest.md`
2. `memory/index.md`
3. `memory/branches/main.md`
4. `Codex工作记忆.md`
5. `项目地图.md`
6. `项目基础盘点.md`
7. `Git仓库洞察.md`
8. `logs/next.md`

## 公开仓库边界

- 论文是规范来源，旧实验仓库只是实现参考。
- 本目录不保存私钥、链数据、实验原始数据或论文未公开内容。
- 长期稳定的公开架构说明应写入 `docs/`；本目录主要记录工作上下文和交接状态。

## 迁移说明

当前采用 embedded 模式，随代码仓库一同管理。目录结构保持可迁移，未来可以独立为单独的 memory repository。
